Résumé de la SAESAE Summary

Cette SAE avait pour but de nous faire découvrir le The goal of this SAE was to introduce us to pentesting via des challenges de type through CTF (Capture The Flag). Le but de ces challenges est d'obtenir une ligne de texte (le flag) en réalisant une tâche se rapprochant, par exemple, de l'exploitation d'une faille dans un environnement volontairement vulnérable. challenges. The objective of these challenges is to obtain a text string (the flag) by performing a task similar to, for example, exploiting a flaw in a deliberately vulnerable environment.

Nous avons eu accès à la version pro de We had access to the pro version of Root-Me, qui propose un parcours adapté au BUT Réseaux et Télécommunications (Parcours EDU | Tronc commun). Ce parcours est constitué de , which offers a path adapted to the Networks and Telecommunications Bachelor's degree (EDU Path | Core curriculum). This path consists of 18 modules, regroupant au total , grouping a total of 75 challenges permettant de découvrir différentes thématiques introductives sur des aspects de la cybersécurité. allowing us to discover various introductory topics on aspects of cybersecurity.

04_thematiques_abordees.md04

Thématiques abordéesTopics Covered

1. Vulnérabilités Web1. Web Vulnerabilities

Introduction à la sécurité des applications web. Exploitation de vulnérabilités classiques telles que les injections SQL (SQLi), les failles XSS, ou encore le contournement d'authentification.Introduction to web application security. Exploitation of classic vulnerabilities such as SQL injections (SQLi), XSS flaws, or authentication bypass.

2. Programmation et Scripting2. Programming and Scripting

Création de scripts d'automatisation. Utilisation des sockets TCP en Python pour interagir dynamiquement avec des services distants afin de résoudre des problèmes mathématiques ou logiques en temps limité.Creation of automation scripts. Use of TCP sockets in Python to dynamically interact with remote services to solve mathematical or logical problems within a time limit.

3. Analyse Réseau3. Network Analysis

Étude approfondie de captures réseau (fichiers PCAP) à l'aide de Wireshark. Compréhension de l'encapsulation, analyse des protocoles et extraction de données en clair telles que des identifiants.In-depth study of network captures (PCAP files) using Wireshark. Understanding encapsulation, protocol analysis, and extracting cleartext data such as credentials.

4. Système Linux4. Linux System

Navigation en ligne de commande, compréhension de la structure des permissions sous Linux, et exploitation de mauvaises configurations pour effectuer des élévations de privilèges.Command-line navigation, understanding the Linux permission structure, and exploiting misconfigurations to perform privilege escalations.
