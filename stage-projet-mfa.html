Objectif du projet :Project Objective:

Au cours de ce projet étalé sur une semaine, le but est de mettre en place une solution de MFA. Cette solution permettra d’approfondir la sécurité chez le client.

During this project spread over a week, the goal is to implement an MFA solution. This solution will deepen security at the client's site.

Situation du client :Client Situation:

L’entreprise dispose d’une infrastructure informatique notamment composée d’un pare-feu WatchGuard, qui permet une connexion via VPN, ainsi que d’un serveur Active Directory synchronisé avec le cloud Microsoft 365. Le client souhaite que ses utilisateurs disposent d’un accès à la suite office 365 et au VPN géré en fonction de la mise en place du MFA ainsi que de leur localisation.

The company has an IT infrastructure notably composed of a WatchGuard firewall, which allows connection via VPN, as well as an Active Directory server synchronized with the Microsoft 365 cloud. The client wants its users to have access to the Office 365 suite and the VPN managed according to the implementation of MFA as well as their location.

Lien avec le parcours cyber : Ce projet s’ancre parfaitement dans mon parcours car il me permet de voir la mise en oeuvre de A à Z d’une couche supplémentaire de sécurité au sein d’une entreprise. Ici, le MFA sert à éviter la compromission du service informatique lors d’une fuite de mots de passe ou d’un phishing.

Link with the cyber track: This project fits perfectly into my track because it allows me to see the implementation from A to Z of an additional security layer within a company. Here, MFA is used to prevent the compromise of the IT service during a password leak or phishing.

03_les_moyens_d_authentificatio.md03

Les Moyens d'AuthentificationAuthentication Methods

Le MFA (Multi-Factor Authentication ou Authentification à Facteurs Multiples) est une méthode qui ajoute une couche de sécurité supplémentaire dans la connexion. Elle est utile quand un utilisateur s’est fait dérober son mot de passe par exemple. Cette méthode se matérialise par l’envoi d’une notification à l’utilisateur après l’entrée de son mot de passe.MFA (Multi-Factor Authentication) is a method that adds an extra layer of security in the connection. It is useful when a user has had their password stolen, for example. This method materializes by sending a notification to the user after entering their password.

Lors de ce projet, nous avons mis en place deux moyens de double-authentification :During this project, we set up two means of two-factor authentication:

Microsoft Authenticator :Microsoft Authenticator:

Authenticator est une application créée par Microsoft qui permet notamment la connexion à la suite Office 365. Lors de la saisie du mot de passe, une pop-up apparaît sur le PC avec un nombre à deux chiffres. L’utilisateur peut alors rentrer ce code sur son téléphone pour se connecter.

Authenticator is an application created by Microsoft that allows, in particular, connection to the Office 365 suite. When entering the password, a pop-up appears on the PC with a two-digit number. The user can then enter this code on their phone to connect.

Token physique :Physical Token (TOTP):

Pour l'alternative physique, nous utilisons le token C202 de token2. Cette fois, lors de la connexion, un code à 6 chiffres est demandé. Celui-ci est généré par le token à l’aide du hash SHA1 de sa seed (clé secrète unique) et d’un facteur de temps.

Token C202 from token2. This time, upon connection, a 6-digit code is requested. This is generated by the token using the SHA1 hash of its seed (unique secret key) and a time factor.
