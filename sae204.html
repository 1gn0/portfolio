Résumé de la SAESAE Summary

Objectif :Objective: Ce projet intégratif a pour but de regrouper les connaissances et projets de la première année au sein d'une même infrastructure. Il s'agit de mettre en place une solution informatique complète pour une entreprise, couvrant le réseau local, la téléphonie IP, la collecte de données via capteurs et leur restitution sur une interface web. This integrative project aims to bring together the knowledge and projects of the first year within a single infrastructure. It involves setting up a complete IT solution for a company, covering the local network, IP telephony, data collection via sensors, and their display on a web interface.

Le projet est divisé en quatre pôles majeurs : The project is divided into four major divisions: RéseauNetworking, TéléphonieTelephony, Collecte IoTIoT Collection et , and Web/BdDWeb/Database.

Mon rôle dans le projetMy role in the project

Lors de cette SAE effectuée en groupe, mon rôle était la récupération des données de température via MQTT et l'affichage de celle-ci sur un site Web. Pour la collecte, j'ai utilisé un script python sur une VM Debian, qui tournait en permanence et était relié à une base de données MariaDB. Cette base de données était elle-même reliée à un site web dynamique créé à l'aide de Django dont le but était d'afficher l'ensemble des données. During this group SAE, my role was to retrieve temperature data via MQTT and display it on a website. For data collection, I used a Python script on a Debian VM, which ran continuously and was connected to a MariaDB database. This database was itself linked to a dynamic website created using Django whose goal was to display all the data.
